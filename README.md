# 💰 Finance Dashboard

A simple and interactive finance dashboard built to help users track their financial activity, analyze spending patterns, and gain useful insights.

## 🧠 Project Overview

This project is designed as a frontend-focused dashboard that allows users to:

* View overall financial summary
* Explore transaction data
* Understand spending behavior through charts
* Gain insights from financial activity

The goal was to build a clean, intuitive interface while keeping the logic simple and maintainable.

---

## ✨ Features

* 📊 Dashboard Overview (Balance, Income, Expenses)
* 📈 Time-based visualization (balance trend)
* 🧩 Category-wise spending breakdown
* 💳 Transactions list with filtering and search
* 🔐 Role-based UI (Admin / Viewer)
* 📉 Insights section (spending patterns and comparisons)
* 📱 Responsive design for different screen sizes

---

## ⚙️ Tech Stack

* React.js
* Tailwind CSS
* JavaScript / TypeScript
* Chart library (Recharts / Chart.js)

---

## 🏗️ Key Technical Decisions

* Used React functional components to keep the code modular and readable
* Chose Tailwind CSS for faster UI development and consistent styling
* Used simple state management instead of Redux to avoid unnecessary complexity
* Separated logic (calculations and insights) from UI components for better maintainability

---

## ⚖️ Trade-offs

* Used mock data instead of backend integration to focus on frontend logic
* Limited advanced filtering and grouping features due to time constraints

---

## 📊 Insights Logic

Insights are dynamically calculated from transaction data instead of being hardcoded.

Examples:

* Highest spending category
* Monthly expense comparison
* Basic financial observations
